Engineering Excellence Program

Build a complete, Well-Architected AWS full stack application from one command, and make AI coding agents build it the right way.

Get it on npm View on GitHub

One command, a whole AWS application

The Engineering Excellence Program (its command is eep) scaffolds a production shaped, deployable AWS full stack app, with every service kept as its own independently validated pack.

npx engineering-excellence init myapp aws-fullstack

Prefer Node.js? Add --backend node. Want serverless? Add --serverless for AWS Lambda and API Gateway.

React on CloudFront

A Vite built React frontend served from a private S3 bucket through a CloudFront CDN over HTTPS.

DynamoDB + Cognito API

A five layer FastAPI service with DynamoDB persistence behind its repository interface and Cognito JSON Web Token authentication guarding the routes.

S3 object storage

An encrypted uploads bucket scoped to the service task role.

AWS CDK pipeline

One CDK stack promoted through dev, uat, and production with an OpenID Connect federated GitHub Actions pipeline.

Doctrine and gates for AI coding agents

Beyond scaffolding, the Engineering Excellence Program installs a corpus of language neutral engineering laws, binds them to real toolchains through golden paths, generates the instruction file each AI agent reads (Claude Code, GitHub Copilot, Cursor, or any agent that reads AGENTS.md), and gates every commit with machine checks. It works on a brand new repository and one running in production for a decade.

npx engineering-excellence fastapi

What it supports

  • Blueprint: aws-fullstack (React, FastAPI, DynamoDB, Cognito, S3, CloudFront, on AWS CDK).
  • Backends: FastAPI and Node.js with TypeScript.
  • Data and storage: Amazon DynamoDB and Amazon S3.
  • Auth and edge: AWS Cognito and Amazon CloudFront.
  • Infrastructure: AWS CDK on Fargate, AWS serverless and API Gateway, containers, and Kubernetes.
  • Delivery: GitHub Actions with OpenID Connect federation.

The laws underneath every pack stay cloud neutral, so an Azure or Google Cloud blueprint reuses them. It is open source under Apache 2.0.
