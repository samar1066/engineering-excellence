# Templates

Canonical shapes every future contributor copies when creating laws, packs, and governed documents. The Engineering Excellence Program provides these templates to ensure consistent frontmatter, structure, and footer formatting across the corpus.

## Overview

These templates define the authoritative structure for all Engineering Excellence Program documentation. Contributors copy these templates when writing new laws or packs, and the corpus check enforces that all files conform to their canonical frontmatter and footer shapes. By standardizing on these structures, we ensure consistency, maintainability, and clear authorship across the entire doctrine corpus.
