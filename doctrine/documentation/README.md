# Documentation

This folder holds the laws that govern how documentation is written and organized across the corpus: frontmatter and attribution, writing style, and the requirement that every content directory explain itself. Contributors read these laws before writing or reviewing any governed document, and a conforming pack's automated checks load them to verify a document or directory before it merges.

## Overview

The documentation domain governs the shape of every governed document in the corpus, independent of what the document says. It sets the mechanical contract for attribution, so every document has a declared owner and a maintainer; the mechanical contract for style, so a corpus written by many hands still reads as one voice; and the structural contract for directories, so a folder never leaves a reader guessing what it contains. None of these laws touch the technical content of a document, only whether it can be trusted, read consistently, and discovered.
