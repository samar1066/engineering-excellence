# Devex

This folder holds the laws that govern developer experience across the corpus, starting with the single requirement that a fresh clone reaches a working setup through one command. Contributors, onboarding tooling, and a conforming pack's automated checks load these laws to verify that getting started with a project never depends on tribal knowledge.

## Overview

The devex domain governs the friction a contributor feels between cloning a repository and making a first change. It currently states one law: that setup collapses into a single documented command wired into the project's own automation, rather than a list of manual steps that only the original author can follow reliably. As the domain grows, further laws will extend this focus to the rest of a contributor's daily experience of the codebase.
