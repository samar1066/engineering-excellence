# {{project_name}} serverless infrastructure

## What this is

This is the serverless infrastructure component of {{project_name}}, generated by `eep init` from the aws-serverless pack. It is a CDK v2 application in TypeScript that deploys one HTTP API on Amazon API Gateway backed by AWS Lambda, instantiated once per environment: `dev`, `uat`, and `prod`. The stage differences (memory, log retention, production protections) live in `lib/environments.ts`, and the shape they share lives in `lib/api-stack.ts`.

## Layout

```
bin/app.ts             one ApiStack per environment, account and region bound at deploy time
lib/environments.ts    dev, uat, and prod, and everything that differs between them
lib/api-stack.ts       the HTTP API, the function, its log group, and the stack outputs
test/api-stack.test.ts assertions over the synthesized template
cdk.json               entry point for the CDK CLI
```

## Setup

Run `make setup` to install dependencies from the committed lockfile.

## Test

Run `make test` to assert against the synthesized template. The suite needs no AWS credentials and makes no network calls.

## Synth

Run `make synth` to render every stage into `cdk.out/`. This is the command the verification gate runs for EEP-IAC-01, so it must pass from a clean checkout with no credentials.

## Preview a change

Run `npm run diff` to render the difference between the deployed stacks and this checkout. Unlike `synth`, `diff` reads deployed state, so it needs credentials. Attach its output to the change under review: it names every resource that will be created, replaced, or destroyed.

## Deploy one stage

`npx cdk deploy --all -c stage=dev` deploys the dev stage, and `uat` or `prod` deploys the others. The stage is always named: without `-c stage=...` every stack is in scope, which is right for `synth` and wrong for a deploy.

## Verify

Run `make verify` to run the full Engineering Excellence Program verification gate. It runs an installed `eep` when there is one and otherwise falls back to `npx engineering-excellence verify`, so Node 22 is its only extra prerequisite.
