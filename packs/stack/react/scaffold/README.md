# {{project_name}}

## What this is

This interface was generated by `eep init` from the react pack. It is a Vite, React 18, TypeScript strict application in three layers (api, hooks, components) with a working notes feature, tests for every primary state, and an accessibility gate that fails the build on a violation. It pairs with a notes API that serves `GET /notes` and `POST /notes`, which the python-fastapi and typescript-node packs both scaffold.

## Setup

Run `make setup` to install the locked dependencies with `npm ci`.

## Test

Run `make test` to run the suite with the coverage gate and then the accessibility gate.

## Verify

Run `make verify` to run the full Engineering Excellence Program verification gate. It runs an installed `eep` when there is one and otherwise falls back to `npx engineering-excellence verify`, so Node 22 is its only extra prerequisite.

## Run

Run `make run` to start the Vite dev server on port 5173. It proxies `/api` to `http://localhost:8000`, so a backend running there needs no extra configuration. Set `VITE_API_URL` when the API lives somewhere else.
